مستمسك برو — تجهيز النشر على GitHub Pages

الحقوق: كرار خيري

الملفات:
- index.html: نسخة النشر التي يفتحها GitHub Pages تلقائياً.
- mustamsak_pro_website.html: نسخة احتياطية من ملف HTML الأصلي كما هو.
- .nojekyll: ملف مساعد للنشر من جذر المستودع.

خطوات النشر:
1. سجّل الدخول إلى https://github.com/ أو أنشئ حساباً.
2. اضغط + ثم New repository.
3. سمِّ المستودع MustamsakPro، واختر Public، ويمكن تفعيل Add a README. لا ترفع صور مستمسكات أو بيانات عائلية.
4. افتح المستودع واضغط Add file ثم Upload files.
5. ارفع index.html و mustamsak_pro_website.html و .nojekyll من هذا المجلد. إذا لم يظهر ملف .nojekyll على الهاتف، يمكن تركه؛ ليس ضرورياً لهذا الملف البسيط.
6. اضغط Commit changes.
7. افتح Settings ثم Pages. تحت Build and deployment اختر Deploy from a branch.
8. اختر Branch: main والمجلد /(root)، ثم Save.
9. انتظر بضع دقائق، ثم افتح الرابط الذي يظهر في صفحة Pages. غالباً يكون بالشكل https://اسم-المستخدم.github.io/MustamsakPro/

تنبيه الخصوصية:
هذا موقع ثابت. النشر لا يرفع الصور المحفوظة محلياً من المتصفح إلى GitHub، لكن رابط الموقع نفسه عام. لا تضع صور هويات حقيقية أو بيانات شخصية في ملفات المستودع. التخزين المحلي مرتبط بالمتصفح والجهاز؛ مسح بيانات المتصفح أو تغيير الجهاز قد يفقدك البيانات، لذا استخدم التصدير الاحتياطي داخل الموقع واحفظ نسخة بمكان آمن.
